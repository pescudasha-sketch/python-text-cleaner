# Simple Python Data Cleaner

Простой и быстрый скрипт на Python для автоматической очистки текстовых файлов от дубликатов, пустых строк и лишних пробелов.

### Что делает скрипт:
- Читает файл построчно.
- Удаляет лишние пробелы по краям (`strip()`).
- Исключает пустые строки.
- Автоматически удаляет дубликаты с помощью множеств (`set`).
- Сортирует результат и сохраняет его в новый файл.

### Как запустить:
1. Поместите файл с данными как `input.txt` в папку со скриптом.
2. Запустите скрипт в терминале:
   ```bash
   python cleaner.py
